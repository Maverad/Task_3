# Задание 3: UI-тесты
## Автотесты для проверки программы, которая помогает заказать бургер в Stellar Burgers

### Реализованные сценарии:

## Профиль:
- Сброс пароля
- Проверка созданного заказа в профиле
- Выход из профиля

## Конструктор:
- Создание заказа 
- Проверка модального окна ингридиента
- Проверка изменения каунтера ингридиента при добавлении в заказ

## Лента заказов:
- Проверка детального окна заказа
- Проверка счетчика заказов "Выполнено за все время"
- Проверка счетчика заказов "Выполнено за сегодня"
- Проверка созданного заказа в блоке "В работе"

## Запуск тестов:
### Запуск тестов в Chrome
- $env:BROWSER="chrome"; pytest

### Запуск тестов в Firefox
- $env:BROWSER="firefox"; pytest
